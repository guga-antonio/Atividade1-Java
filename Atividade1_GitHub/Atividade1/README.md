# Atividade 1 — Java

Projeto desenvolvido no NetBeans para praticar Programação Orientada a Objetos em Java.

## Organização
- `Principal.java`: ponto de entrada do programa.
- `PacoteViagem.java`: classe relacionada ao pacote de viagem.
- `Hospedagem.java`: representa informações de hospedagem.
- `Transporte.java`: representa informações de transporte.
- `Venda.java`: reúne a lógica relacionada à venda.

## Tecnologias
- Java
- Apache NetBeans

## Como abrir
1. Baixe ou clone este repositório.
2. No NetBeans, selecione **File > Open Project**.
3. Escolha a pasta do projeto.
